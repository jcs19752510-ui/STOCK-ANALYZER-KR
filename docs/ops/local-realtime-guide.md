# 내 PC 실시간 시세 사용 가이드 (DEC-084)

## 1. 한 줄 요약과 범위
**내 PC에서, 나 혼자, 종목 상세 화면의 현재가·호가·체결·분/틱 차트를 실시간으로 보는 기능**입니다. 한국투자증권 실시간(웹소켓) 서비스를 내 앱키로 씁니다.

- 내 PC 전용·본인 전용입니다. 다른 사람에게 보여 주는 용도가 아닙니다.
- 동시에 볼 수 있는 종목은 **20개**까지입니다(종목마다 체결·호가 2건씩, 증권사 한도 40건).
- 시세는 **통합시세**입니다. 한국시간 평일 **08:00~20:00**에만 값이 들어옵니다. 그 밖의 시간·휴장일에는 체결이 없는 것이 정상입니다.
- 주문·계좌 조회는 하지 않습니다(시세 수신만).

## 2. 준비 (한 번만)
1. **앱키 발급**: `docs/ops/local-intraday-guide.md`의 1절을 따라 실전투자 앱키(APP KEY)·시크릿(APP SECRET)을 발급받습니다. 이미 분봉·호가를 쓰고 있다면 같은 앱키를 그대로 씁니다.
2. 프로젝트 폴더의 `.env` 파일에 아래 세 줄이 있어야 합니다(이미 있으면 그대로 둡니다).
   ```
   LOCAL_INTRADAY_ENABLED=true
   KIS_APP_KEY=발급받은_앱키
   KIS_APP_SECRET=발급받은_시크릿
   ```
3. `frontend\.env.local` 파일에 아래 한 줄이 있어야 합니다.
   ```
   NEXT_PUBLIC_LOCAL_INTRADAY_ENABLED=true
   ```
앱키·시크릿은 채팅·메일·화면 캡처에 올리지 마세요. 이 기능의 점검 도구도 앱키를 화면에 출력하지 않습니다.

## 3. 로그인을 켠 로컬이라면
`로컬서버-접속방법.md` 4-1절처럼 로컬에서도 로그인을 켜 두었다면, **관리자 계정으로 로그인해야** 실시간이 보입니다. 일반 회원 계정으로는 실시간이 나오지 않습니다(본인 전용 기능이라 서버가 관리자인지 확인합니다). 로그인을 껐다면(`setup_local_auth.py --off`) 로그인 없이 바로 쓸 수 있습니다.

## 4. 실행 순서
설정은 시작할 때만 읽으므로, 위 설정을 바꿨다면 **API와 웹을 모두 다시 시작**합니다.

PowerShell 창 1 (API):
```powershell
powershell -ExecutionPolicy Bypass -File scripts\start_local_api.ps1
```
PowerShell 창 2 (웹):
```powershell
cd frontend
npx next dev -p 4000
```
브라우저에서 `http://localhost:4000/stocks/005930`을 엽니다.

## 5. 장중 확인: 증권사 연결 점검 도구
화면을 보기 전에, 증권사 실시간이 내 PC에서 되는지 **한 번에** 확인합니다. **장 시간(평일 08:00~20:00)에 실행**하세요.
```powershell
py -3.12 scripts\kis_ws_smoke_test.py
py -3.12 scripts\kis_ws_smoke_test.py --code 000660 --seconds 30     # 다른 종목, 30초(최대 120초)
```
20초 동안 삼성전자의 체결·호가를 받아 값이 올바른지 검사합니다. 결과 읽는 법:

| 표시 | 뜻 |
|---|---|
| `[OK] 접속키 발급` | 앱키·시크릿이 맞고 증권사가 접속키를 내줌 |
| `[OK] 웹소켓 접속` | 증권사 실시간 서버에 연결됨 |
| `구독 응답 2/2` | 체결·호가 요청을 증권사가 받아들임 |
| `체결 N건, 호가 N건, PINGPONG N회` | 실제로 받은 개수. 장중 삼성전자는 보통 체결·호가가 여러 건 옴. PINGPONG은 증권사의 연결 확인 신호(자동 응답함) |
| `첫 체결까지 N초` | 구독 후 첫 체결이 온 시간 |
| `PC 시계 차이` | 체결 시각과 내 PC 시계의 차이. **0~수 초가 정상**. 크면 Windows 시간 동기화 필요 |
| `[OK] 값 검증` | 현재가>0, 시각 형식, 호가 10단계 순서, 총잔량≥0, 누적 거래량 증가가 모두 정상 |
| `[확인필요]` | 문제는 아니지만 판단할 수 없음(예: 장 시간 밖). 사유가 함께 나옴 → 장중에 다시 실행 |
| `[실패]` | 연결·구독·값에 문제. 사유가 함께 나옴 |

종료 코드: `0` 정상, `1` 실패, `2` 확인필요(`echo $LASTEXITCODE`로 확인). **`[실패]`가 나오면 출력 내용(앱키는 나오지 않음)을 그대로 알려 주세요.**

## 6. 화면에서 확인하는 법
종목 상세 화면에서 호가·체결·차트 탭을 엽니다. 연결 상태가 화면에 표시됩니다(예정 문구: "실시간 연결됨", "재연결 중", "끊김, 마지막 수신 시각").
- 장중에 현재가·호가가 1~2초 안에 계속 바뀌면 정상입니다.
- 종목 화면을 닫아도 약 30초는 구독을 유지합니다(새로고침할 때 끊었다 붙이지 않기 위함). 그 뒤 자동으로 해지됩니다.
- 분·틱 차트를 고르면 오늘 분봉은 증권사 조회로 먼저 채우고, 이후는 실시간으로 이어집니다.

## 7. 문제 해결
| 증상 | 원인 | 조치 |
|---|---|---|
| 배지가 "끊김"/"재연결 중"에서 안 바뀜 | 인터넷 끊김, 장 시간 밖, 증권사 접속 문제 | 5절 점검 도구를 실행해 어느 단계에서 막히는지 확인. 장 시간 밖이면 정상 |
| 화면에 값이 없음(장중) | 관리자 계정이 아님, 설정 누락, 재시작 안 함 | 3절 확인 → 2절 설정 확인 → API·웹 재시작 |
| 429 "동시에 볼 수 있는 종목은 20개까지" | 20종목 한도 초과 | 열어 둔 종목 탭을 닫고 약 30초 뒤 다시 |
| 503 "증권사 앱키가 설정되지 않았습니다" | API가 `KIS_APP_KEY`·`KIS_APP_SECRET`을 못 읽음 | `.env` 확인 후 API 재시작(`scripts\start_local_api.ps1` 사용) |
| 403 접근 권한 없음 | 관리자가 아닌 계정, 또는 프록시·터널·공개 주소로 접속 | 관리자로 로그인, `http://localhost:4000`으로 직접 접속 |
| 점검 도구 `[실패] 접속키 발급 … HTTP 4xx` | 앱키·시크릿 오타, 실시간 서비스 미신청, 증권사 점검 | `.env` 값 재확인, 증권사 사이트에서 신청 상태 확인 |
| 점검 도구 `접속키 오류(OPSP0011)` | 증권사가 접속키를 인정하지 않음 | 잠시 뒤 재실행, 계속되면 앱키 재확인 |
| 점검 도구 `[실패] 웹소켓 접속` 또는 접속키 발급 단계에서 서버에 연결하지 못함 | 인터넷·방화벽, **해외 IP**(VPN·해외 서버에서는 막힐 수 있음) | VPN을 끄고 국내 인터넷에서 실행. 회사·학교망은 21000번 포트가 막혔을 수 있음 |
| 점검 도구 `[확인필요] … 장 시간 밖` | 평일 08:00~20:00이 아님 | 장중에 다시 실행 |
| 점검 도구 `[확인필요] 장 시간인데 체결이 없었습니다` | 공휴일·휴장일이거나 거래가 드문 종목 | 평일 장중에 삼성전자(기본)로 다시 실행 |
| 점검 도구 `[실패] 값 이상` | 증권사가 예상과 다른 값을 줌(필드 순서 변경 등) | 출력 전체를 알려 주세요(앱키는 나오지 않음) |

## 8. 끄는 법
- 실시간만 끄기: `.env`의 `LOCAL_INTRADAY_ENABLED` 줄을 지우거나 `false`로 바꾸고 API를 다시 시작합니다(분봉·호가 조회도 함께 꺼집니다).
- 화면의 탭까지 숨기기: `frontend\.env.local`의 `NEXT_PUBLIC_LOCAL_INTRADAY_ENABLED` 줄을 지우고 웹을 다시 시작합니다.

## 9. 알아둘 점
- **틱은 저장하지 않습니다.** 받은 체결·호가는 메모리에만 있고 서버를 끄면 사라집니다. 과거 데이터는 DB에 쌓이지 않습니다.
- **증권사 웹소켓 주소가 `ws://`(암호화 없음)입니다.** 시세와 접속 요청이 암호화되지 않고 오갑니다. **공개 와이파이(카페·공항 등)에서는 쓰지 마세요.** 집·사무실의 믿을 수 있는 망에서만 쓰세요.
- **서버(Render) 경유는 지금 사용하지 않습니다.** 증권사 시세를 서버로 올려 여러 사람에게 보여 주려면 약관·거래소 정보이용계약 확인이 먼저입니다. 확인 전까지는 이 기능을 켠 채로 외부에 공개하거나 터널(ngrok 등)로 열지 마세요.
- 앱키 하나로 실시간 연결은 **1개**만 유지합니다. 같은 앱키로 다른 프로그램이 실시간에 접속해 있으면 서로 끊을 수 있습니다.
