# 사용자 직접 진행 가이드 (쉬운 설명판, 2026-10-02)

개발은 끝났고, 아래 3가지만 사용자가 직접 하면 됩니다. **순서: ① 배포 설정·스케줄러 → ② 화면 검수 → ③ 법률 확인.**
(①②는 오늘 바로 가능, ③은 답변을 기다리는 시간이 걸리므로 **먼저 문의부터 보내 두세요**.)

---
## 1. 배포 설정과 스케줄러 등록 (약 15분)

### 1-1. 비밀 토큰 만들기 (프론트→API 호출에서 방문자 IP를 인정받는 열쇠)
PowerShell에서 한 줄 실행 → 나온 긴 문자열을 복사해 둡니다.
```
py -3.12 -c "import secrets; print(secrets.token_urlsafe(32))"
```

### 1-2. 설정 파일에 값 넣기
1. 프로젝트 루트 `.env`(백엔드/배치용)에 추가:
```
PUBLIC_API_INTERNAL_TOKEN=<위에서 만든 문자열>
DATA_FRESHNESS_WEBHOOK_URL=<선택: Slack/Discord 웹훅 주소, 없으면 줄 생략>
```
2. `frontend\.env.local`(프론트용)에 추가 — **같은 토큰**:
```
PUBLIC_API_INTERNAL_TOKEN=<같은 문자열>
FRONTEND_TRUSTED_PROXY_HOPS=0
```
- `FRONTEND_TRUSTED_PROXY_HOPS`는 지금처럼 내 PC에서만 돌릴 때는 **0**. 나중에 서버 앞에 프록시(Cloudflare, nginx 등)를 한 겹 두면 **1**.
- 토큰 줄 앞에 `NEXT_PUBLIC_`을 **절대 붙이지 마세요**(붙이면 브라우저에 노출됩니다).
3. API를 켤 때 토큰이 API 프로세스 환경에 있어야 합니다. 기존 방식(`로컬서버-접속방법.md` §2)의 `eval "$(grep -E '^(PUBLIC_API_DATABASE_URL|PUBLIC_API_CORS_ALLOWED_ORIGINS)=' .env ...)"` 줄의 괄호 안에 `|PUBLIC_API_INTERNAL_TOKEN`을 추가하세요.
4. API와 프론트를 다시 시작합니다(프론트는 `next dev`면 자동 반영, 운영 빌드면 재빌드).

### 1-3. 배치 스케줄러 등록 (한 번만)
1. 프로젝트 폴더에서 PowerShell을 엽니다(`C:\big21\vibe-coding\STOCK-ANALYZER-KR`).
2. 실행:
```
powershell -ExecutionPolicy Bypass -File scripts\register_daily_batch_task.ps1
```
3. 표가 나오면 성공: `StockScreenerKR-DailyBatch`, `StockScreenerKR-FreshnessCheck`가 `Ready`.
   (기존 07:00 작업은 같은 이름으로 자동 교체됩니다. 되돌리기: 같은 명령 끝에 `-Remove`)
4. 지금 바로 한 번 돌려 보기(누락된 09-22·23·30, 10-01을 채웁니다):
```
py -3.12 scripts\run_daily_batch.py
```
   끝에 `[완료]`가 보이면 정상. `[대기]`(종료코드 2)는 "아직 오늘 자료가 안 올라옴"이라 정상이며 오후에 자동 재시도됩니다.
5. 다음 날 `logs\daily_batch.log` 맨 아래에 `exit=0`이 있는지 확인.
6. PC가 꺼져 있어도 켜면 실행되지만, **14:30·18:30에 PC가 켜져 있어야 가장 안정적**입니다.

### 1-4. 진짜 서버에 올릴 때만 (지금은 건너뛰어도 됨)
- `PUBLIC_API_CORS_ALLOWED_ORIGINS`를 실제 사이트 주소(`https://내도메인`)로, 사이트는 HTTPS로 운영.
- 공공데이터포털 마이페이지에서 **일일 호출 한도** 확인(배치 1회 ≈ 6~7회 호출 × 날짜 수).

## 2. 화면 검수 (R4·R8)

### 2-1. PC에서 휴대폰 화면으로 보기 (실기기 없이 5분)
1. 크롬에서 `http://localhost:4000/stocks/005930` 열기 → `F12` → 왼쪽 위 휴대폰 아이콘(`Ctrl+Shift+M`).
2. 기기를 `iPhone SE`(작은 화면), `iPhone 14`, `Galaxy S20`로 바꿔 가며 아래를 봅니다.
   - 좌우로 흔들리는 가로 스크롤이 없다 / 글자가 잘리지 않는다
   - 탭·버튼이 손가락으로 누르기 충분히 크다
   - 시세 공개가 **꺼진 기본 상태**: 현재가·차트가 없고 "시세 원본이 아닌 가공 지표를…" 안내, 실적·투자자(준비 중)·조건 체크 탭이 보인다
3. 같은 방법으로 `/`, `/screener`, `/screener/pattern`도 확인. 어색한 화면은 캡처해서 알려주세요 — 제가 고치겠습니다.

### 2-2. 진짜 휴대폰으로 보기 (선택, 같은 와이파이)
1. PC IP 확인: PowerShell `ipconfig` → `IPv4 주소`(예: 192.168.0.12).
2. `frontend\.env.local`의 `NEXT_PUBLIC_API_BASE_URL=http://192.168.0.12:4001`, `.env`의 `PUBLIC_API_CORS_ALLOWED_ORIGINS=http://192.168.0.12:4000`로 바꾸고 둘 다 재시작.
3. 프론트는 `npx next dev -p 4000 -H 0.0.0.0`로 실행. Windows 방화벽 팝업이 뜨면 "허용".
4. 휴대폰 브라우저에서 `http://192.168.0.12:4000`. (끝나면 설정을 원래대로 되돌리세요.)

### 2-3. 시세 공개를 켠 모습도 보고 싶다면 (테스트용, 외부 공개 금지)
`.env`에 `PUBLIC_API_PRICE_EXPOSURE_ENABLED=true`, `frontend\.env.local`에 `NEXT_PUBLIC_PRICE_EXPOSURE_ENABLED=true` → 재시작/재빌드. 확인 후 **꼭 지우거나 false**로.

## 3. 법률·약관 확인 (R3) — 제일 오래 걸리니 먼저 문의
**왜 필요한가**: 공공데이터포털 주식시세 데이터 약관에 "상업 목적 여부와 상관없이 제3자 무단 제공·재배포 금지"가 있습니다. 그래서 시세 원값(시가·고가·저가·종가·거래량) 공개를 **기본 꺼둔 상태**입니다. 서비스는 이대로(가공 지표만) 배포해도 됩니다. 원값을 보여주고 싶을 때만 아래 확인이 필요합니다.

**누구에게**: ① 공공데이터포털 해당 API 상세페이지의 문의(Q&A) 또는 고객센터, ② 한국거래소(KRX) 데이터 마켓플레이스 문의, ③ (권장) 자본시장·저작권 경험 있는 변호사 1회 자문.

**그대로 복사해 보낼 문의문**
> 개인이 개발 중인 무료 주식 정보 웹서비스에서 "금융위원회_주식시세정보" Open API 데이터를 사용합니다. 하루 1회 수집해 (1) 가공 지표(등락률, 이동평균 괴리율, 거래량 이상치 등)를 계산해 보여주고, (2) 종목 상세 화면에 종목별 일봉(시가·고가·저가·종가·거래량)과 차트를 일 단위 종가 기준으로 보여주려 합니다. 실시간 시세는 아니며 이용자에게 무료입니다. 질문: ① (2)와 같은 원값 표시가 약관의 "제3자 제공·재배포"에 해당합니까? ② 해당한다면 무료 개인 서비스에서 허용되는 방법(출처 표기, 지연 표시, 이용 계약 등)이 있습니까? ③ 가공 지표만 보여주는 (1)은 문제가 없습니까?

**결과에 따라**
| 답변 | 할 일 |
|---|---|
| 원값 표시도 가능 | 2-3처럼 두 스위치를 켜고(운영은 재빌드) 이후 배포 |
| 불가 / 계약 필요 | 지금 상태(꺼짐) 그대로 배포 — 추가 작업 없음 |
| 답이 없음 | 꺼진 상태로 배포 |

**함께 확인할 것(문의 때 같이)**: DART 공시 재무 수치(실적 탭) 이용 조건·출처 표기 의무(opendart 이용약관), 서비스 명칭 "Q4" 사용 가능 여부(상표·표현), 면책 문구 최종 점검.
