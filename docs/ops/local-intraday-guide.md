# 개인 로컬 모드 사용 가이드 — 분봉·틱·호가·체결 (DEC-052)

> **실시간(웹소켓) 시세**를 쓰려면 이 문서 대신 [local-realtime-guide.md](local-realtime-guide.md)를 보세요(이 문서의 앱키 준비 1절은 공통입니다).

**한 줄 요약**: 내 한국투자증권 앱키로 내 PC에서만 분봉·틱·호가·체결을 보는 기능입니다. **인터넷에 공개하는 서버에서는 절대 켜지 마세요.**
(증권사 시세를 불특정 다수에게 보여주려면 거래소와의 정보이용계약이 필요합니다 — `docs/stock-detail/04-intraday-options.md`)

## 0. 먼저 알아둘 것
- 기본은 **꺼짐**입니다. 아래 설정을 하지 않으면 화면에 호가·체결 탭이 없고 분·틱 버튼은 회색(비활성)입니다.
- 읽기 전용입니다. **주문·계좌 조회는 호출하지 않습니다**(시세 조회 5개 엔드포인트만).
- 앱키·시크릿은 `.env`(git 제외)에만 둡니다. 화면(브라우저)·로그·응답에는 나오지 않습니다.
- 증권사 호출 한도를 지키기 위해 요청 간격을 두고 짧게 캐시합니다(분봉 5초, 체결 2초, 호가 1초).

## 1. 앱키 준비 (한 번만)
1. 한국투자증권 계좌가 있어야 합니다. KIS Developers(https://apiportal.koreainvestment.com)에서 Open API 서비스를 신청하고 **실전투자 앱키(APP KEY)와 시크릿(APP SECRET)**을 발급받습니다.
   (화면 구성·절차는 증권사 사정으로 바뀔 수 있습니다. 막히면 증권사 고객센터에 문의하세요.)
2. 발급받은 두 값을 **다른 사람에게 보여주거나 채팅·메일·스크린샷에 넣지 마세요.** 노출되면 증권사 사이트에서 즉시 재발급하세요.

## 2. 설정
프로젝트 루트 `.env`에 추가(이미 있는 줄은 두고 아래만 추가):
```
LOCAL_INTRADAY_ENABLED=true
KIS_APP_KEY=발급받은_앱키
KIS_APP_SECRET=발급받은_시크릿
```
`frontend\.env.local`에 추가:
```
NEXT_PUBLIC_LOCAL_INTRADAY_ENABLED=true
```
(시세 공개 스위치는 기본 켜짐이므로 별도 설정이 필요 없습니다. 꺼 둔 상태면 호가·체결도 숨겨집니다.)

## 3. 실행
`로컬서버-접속방법.md`의 백엔드 기동에서 환경변수를 올리는 줄의 목록에 새 변수를 추가합니다.
```bash
eval "$(grep -E '^(PUBLIC_API_DATABASE_URL|PUBLIC_API_CORS_ALLOWED_ORIGINS|PUBLIC_API_INTERNAL_TOKEN|LOCAL_INTRADAY_ENABLED|KIS_APP_KEY|KIS_APP_SECRET)=' .env | tr -d '\r')"
```
API를 시작한 뒤, 프론트는 **다시 시작**합니다(`cd frontend` → `npx next dev -p 4000`. 운영 빌드라면 `npm run build` 후 `npm start`).

## 4. 실제 앱키로 연동 확인 (꼭 한 번, 장중 권장)
```
py -3.12 scripts\kis_smoke_test.py
py -3.12 scripts\kis_smoke_test.py 000660     # 다른 종목
```
- 호가·체결·1분봉·5분봉·투자자별 순매수가 `[OK]`로 나오면 연결 성공입니다. 투자자 줄에는 개인·외국인·기관 수량과 대금이 한 줄로 나오니 **증권사 앱의 같은 종목·같은 날짜 값과 비교해 단위(수량 주, 대금 백만원)가 맞는지** 한 번 확인해 주세요. 앱키·토큰은 출력되지 않습니다.
- `[확인필요]`: 장 시작 전·휴장일이면 정상일 수 있습니다. 장중(09:00~15:30)에 다시 실행하세요.
- `[실패] … AUTH_FAILED`: 앱키·시크릿 오타 또는 서비스 미신청. `[실패] … UPSTREAM_ERROR`: 증권사 메시지가 함께 나옵니다.
- **실패하거나 필드가 비어 있으면 출력 내용(앱키 제외)을 그대로 알려 주세요.** 개발 환경에서는 증권사 서버에 접속할 수 없어 이 단계만 실제 응답으로 확인하지 못했습니다.

## 5. 화면에서 쓰는 법
- 종목 상세(`http://localhost:4000/stocks/005930`)에 **호가 · 차트 · 체결** 탭이 생기고, **투자자** 탭에는 일별 개인·외국인·기관 순매수(▲순매수/▼순매도, 수량 주·대금 백만원, 최근 30거래일, 30초 갱신)가 표시됩니다. 당일 값은 장 마감 후 확정되어 장중에는 빠질 수 있습니다. 공개 화면에서는 이 탭이 계속 "준비 중"입니다.
- 차트 탭의 **분▾**: 1·3·5·10·15·30·60분 중 선택. **틱▾**: 1·3·5·10·30틱 묶음(최근 체결 300건 기준).
- 장중에는 분·틱 차트가 자동 갱신됩니다(분봉 10초, 틱 5초). 호가 2초, 체결 3초.
- **일·주·월**을 누르면 다시 일봉 차트입니다.
- 검은 별 모양 버튼 **차트 요약**: 화면의 수치를 문장으로 옮긴 사실 요약입니다(전망·투자 판단 아님).

## 6. 앱키 없이 화면만 체험 (모의 서버)
증권사 서버가 아닌 **가짜 시세**입니다. 화면 동작 확인용으로만 쓰세요.
```
py -3.12 scripts\mock_kis_server.py --port 9100
```
`.env`에 임시로 `KIS_APP_KEY=mock`, `KIS_APP_SECRET=mock`, `KIS_BASE_URL=http://127.0.0.1:9100`, `KIS_ALLOW_CUSTOM_BASE_URL=true`를 넣고 API를 재시작합니다. 끝나면 이 줄들을 지우세요.

## 7. 문제 해결
| 증상 | 원인·조치 |
|---|---|
| 호가·체결 탭이 안 보임 | `NEXT_PUBLIC_LOCAL_INTRADAY_ENABLED=true` 후 **프론트를 다시 빌드/시작**했는지, 주소가 `localhost`·`192.168.x.x`인지(공개 도메인이면 숨김) |
| "개인 로컬 모드가 꺼져 있습니다" | API의 `LOCAL_INTRADAY_ENABLED=true`, **API 재시작**, 프록시/터널 없이 직접 접속했는지(프록시 헤더가 있으면 거부) |
| "앱키가 설정되지 않았습니다" | `KIS_APP_KEY`·`KIS_APP_SECRET`이 API 프로세스 환경에 올라갔는지(3번의 `eval` 목록) |
| "증권사 인증에 실패했습니다" | 앱키·시크릿 재확인, 서비스 신청 상태 확인. 토큰은 6시간에 1회만 새로 받을 수 있으니 자주 재시작해도 `.local/kis_token.json`을 재사용합니다 |
| "호출 한도를 초과했습니다" | 잠시 후 자동 재시도합니다. 탭을 여러 개 열어 두지 마세요 |
| 분봉이 비어 있음 | 장 시작 전·휴장일이면 직전 거래일 분봉을 보여줍니다. 그래도 비면 스모크 테스트 결과를 알려 주세요 |

## 8. 안전 수칙 — 하지 말 것
1. 이 기능을 켠 채로 **ngrok·Cloudflare Tunnel·포트포워딩·리버스 프록시로 외부에 노출**하지 마세요. (프록시 헤더가 있으면 거부하도록 막아 두었지만 우회 가능한 설정이 있을 수 있습니다.)
2. `LOCAL_INTRADAY_ALLOWED_IPS`를 `0.0.0.0/0` 등 넓게 열지 마세요. 같은 와이파이의 휴대폰으로 볼 때만 `192.168.0.0/24`처럼 필요한 대역만 추가하세요.
3. 화면 캡처·화면 공유로 증권사 시세를 타인에게 제공하지 마세요.
4. `.env`, `.local/` 폴더를 커밋하거나 공유하지 마세요(git에서 제외돼 있습니다).
5. **외부 공개 배포에서는** API의 `LOCAL_INTRADAY_ENABLED`를 설정하지 않고(=꺼짐) 프론트의 `NEXT_PUBLIC_LOCAL_INTRADAY_ENABLED`도 설정하지 않은 채 빌드하세요.

## 9. 끄는 방법
`.env`의 `LOCAL_INTRADAY_ENABLED` 줄을 지우고(또는 `false`) API를 재시작합니다. 프론트는 `NEXT_PUBLIC_LOCAL_INTRADAY_ENABLED` 줄을 지우고 다시 빌드/시작합니다.
