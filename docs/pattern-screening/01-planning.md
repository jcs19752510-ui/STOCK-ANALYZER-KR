## 1. 배경과 목적

사용자가 ChatGPT와 정한 "급등 전 압축주" 선발 기준 10가지를, 이미 운영 중인 **조건 기반 스크리닝 서비스**(`/screener`, `GET /api/v1/screen`)에 **하나의 패턴 조건 세트**로 이식한다. 사람이 증권사 앱 차트를 하나씩 열어 이동평균선·거래량을 눈으로 대조하던 작업을, 전 종목에 대해 같은 수치 기준으로 자동 점검하는 것이 목적이다.

### 1-1. 사용자 확정 사항 (2026-10-02, AskUserQuestion 응답 4건 → `decisions.md` DEC-032)

| # | 질문 | 사용자 결정 |
|---|---|---|
| 1 | 사용 범위 | **공개 서비스 기능** — 일반 사용자용 화면, 기존 규제·보안 규칙 전부 적용 |
| 2 | 개발 범위 | **1단계만 상세 + 2·3단계는 로드맵** |
| 3 | 임계값 | **제가 기본값 제안 + 설정값으로 분리**(사용자 확정 대기 표시) |
| 4 | 표현 방침 | **원문 표현 유지 — "급등 전 압축주"** |

### 1-2. ⚠ 결정 4번이 기존 결정과 충돌하는 지점 (명시 기록)

- `DEC-003`은 "추천 주식 분석"을 "조건 기반 스크리닝"으로 **의도적으로 리프레이밍**했고, `REQ-008`·`04-ux-design.md §2-6`은 순위·예측으로 오인될 표현을 금지한다. "급등 전"은 **이후 가격 상승을 전제로 한 예측 표현**이라 이 취지와 긴장 관계에 있다. 기존 금지어 린트(`frontend/scripts/lint-forbidden-copy.mjs`)의 목록에는 "급등"이 없어 **기계적으로는 통과하지만 취지상 위험이 남는다.**
- 이 문서는 사용자 결정을 **그대로 따른다.** 대신 위험을 줄이는 장치를 **설계에 내장**한다(사용자가 원하면 제거 가능):
  1. 명칭을 코드 상수 **한 곳**(`copy.ko.json` `pattern.label`)에만 두어, 법률 검토 결과에 따라 **재개발 없이 한 줄로 변경**.
  2. 패턴 화면 상단에 "예측·권유가 아니다"라는 상시 고지(`PatternNotice`, 기존 CSS 클래스 `inline-notice--info` 사용) — 디자인서 §4.
  3. 점수·순위·"가장 유력" 같은 서열화 표현 금지 — 조건별 충족/미충족/산정불가만 표시.
  4. `REQ-022`(배포 전 법률/KRX 확인 게이트)의 확인 범위에 **"패턴 명칭·표현"을 명시적으로 추가**(REQ-034).
- 법적 판단은 이 문서가 확정하지 않는다. **공개 배포 승인(규칙 E) 전에 이 명칭에 대한 법률 검토가 필요하다.**

## 2. 사용자 가치와 페르소나

기존 P2/P3(조건을 스스로 조합하는 개인투자자)의 확장이다. 가치 가설: "차트 패턴 기준을 매번 눈으로 확인하지 않고, **같은 정의로 전 종목에서 해당 종목을 한 번에 본다.**" 서비스는 종목을 **판단하지 않고** 사용자가 이미 정한 수치 조건에 해당하는지를 **사실로 표시**한다.

### 3-1. 10개 기준 → 이번 릴리스 처리 방식

| 원문 기준 | 조건 ID | 데이터 | 이번 릴리스 |
|---|---|---|---|
| 1 긴 횡보 | **c1** | 일봉 종가(최근 80거래일) | ✅ 구현 |
| 2 5·10·20일선 수렴 | **c2** | 일봉 종가 | ✅ 구현 |
| 3 60일선 접근 | **c3** | 일봉 종가 | ✅ 구현 |
| 4 60일선 돌파 직전/초기 | **c4** | 일봉 종가 | ✅ 구현 |
| 5 거래량 폭발 전 | **c5** | 일봉 거래량 | ✅ 구현 |
| 6 외국인·기관 누적 수급 | — | 투자자별 수급(**미보유**) | 🗺 로드맵 3단계(REQ-038) |
| 7 개인 주도 제외 | — | 투자자별 수급(**미보유**) | 🗺 로드맵 3단계(REQ-038) |
| 8 실적 개선 가능성 | — | DART 매출·영업이익(현재 순이익·자본만) | 🗺 로드맵 2단계(REQ-037) |
| 9 호재 반영 종목 제외 | **c9** | 뉴스 데이터 없음 → **가격·거래량 이력으로 대체** | ✅ 대체 구현(뉴스 자체는 범위 밖) |
| 10 최종 위치(종합) | — | c1~c5·c9의 조합 | ✅ 구현(`required` 선택 조합) |

> c9는 원문이 말한 "뉴스 반영 여부"를 **직접 판정하지 못한다.** "최근 20거래일 내 급등+거래량 폭발 이력이 있는가"라는 가격·거래량 대리 지표(proxy)이며, 화면과 문서에서 대리 지표임을 숨기지 않는다.

### 3-2. 범위 밖 (명시)
수급·실적·뉴스 기반 판정, 알림/구독, 사용자 맞춤 임계값 입력, 백테스트/수익률 통계, 종목 점수화·순위화, 개별 종목 상세 화면의 패턴 표시.
