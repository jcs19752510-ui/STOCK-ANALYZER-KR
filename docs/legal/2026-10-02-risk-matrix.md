# 쟁점·위험 매트릭스 (2026-10-02)

> **법률 자문이 아닙니다.** 위험도는 "확인되지 않은 쟁점이 얼마나 크게 서비스에 영향을 줄 수 있는가"에 대한 조사원의 정리이며 위법 여부 판단이 아닙니다. 각 쟁점은 "원문상 ~ / 해석 여지 / 변호사 확인 필요" 3단 구조로 씁니다. 원문은 대부분 **미열람**이므로(`2026-10-02-terms-fact-sheet.md` §1) "원문상" 항목은 저장소가 인용한 문구 또는 2차 출처를 가리킵니다.
> 위험도: 상/중/하/판단 유보. "판단 유보"는 원문 부재로 등급을 매기지 않음.

## 2. 시세 원값 공개 스위치를 끄면 줄어드는 위험

대상 스위치: API `PUBLIC_API_PRICE_EXPOSURE_ENABLED=false`(요청 시점 평가), 프론트 `NEXT_PUBLIC_PRICE_EXPOSURE_ENABLED=false`(빌드 시점, 재빌드 필요). 근거: `docs/harness/decisions.md` DEC-048·050, `services/public_api/api/prices.py`, `frontend/src/lib/priceExposure.ts`.

| 항목 | 켜짐(현재 기본) | 꺼짐 |
|---|---|---|
| `/stocks/{code}/prices`, `/stocks/quotes` | 시가·고가·저가·종가·거래량 응답 | 404 FEATURE_DISABLED |
| 종목 상세 현재가·차트·일자별 시세·목록 시세 | 노출 | 숨김, 안내 문구(`pricesHiddenNote`) |
| 개인 로컬 모드 UI | 시세 공개가 켜져 있어야 노출 가능(`localIntraday.ts`) | 노출 불가 |
| 줄어드는 쟁점 | — | 표 1의 #1(원값 재배포)이 가장 크게 감소. #11(차트 요약 문장 속 가격 수치) 감소 가능. #6 중 UI 경로 감소 |
| **줄어들지 않는 쟁점** | — | #3·#4(가공 지표·근거 수치), #5(DART), #7 출처표시, #9·#10 투자권유·명칭, #12 상표, #13 개인정보, 그리고 **원천 데이터를 서버에서 수집·저장·가공하는 행위 자체**(원문상 "이용"과 "제공"의 구분은 변호사 확인 필요) |

주의: 스위치를 꺼도 DB `daily_prices` 테이블과 API 코드는 유지됨(DEC-048). 원본 수집(`raw_internal`)과 가공 지표는 계속 공개됨.
