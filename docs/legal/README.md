## 지금 해야 할 일 (순서)
1. 데이터셋 15094808 페이지(https://www.data.go.kr/data/15094808/openapi.do)를 본인 브라우저로 열어 이용허락범위·상세설명을 캡처하고, `02-planning.md` §4-3 인용과 대조.
2. 공공데이터포털·KRX·OpenDART·KIS 약관 원문을 저장(열람일시 기록).
3. `inquiry-drafts.md`의 문의 중 (a)(b)를 먼저 발송(답변이 오래 걸림).
4. 외부 공개 배포가 가까우면 `PUBLIC_API_PRICE_EXPOSURE_ENABLED=false`, `NEXT_PUBLIC_PRICE_EXPOSURE_ENABLED=false`(프론트 재빌드) 상태로 두는 것을 우선 검토하고, 푸터·서비스 안내 문구와 실제 화면의 불일치(risk-matrix §5-A)를 정리.
5. `lawyer-brief.md`로 변호사 상담 예약·준비.
6. 결과를 `docs/harness/decisions.md`에 기록(REQ-022 게이트).
7. 체크리스트의 "서비스 명칭 Q4(DEC-014)"는 오기로 보이므로 `fact-sheet` §6 기준으로 실제 대상("급등 전 압축주", 서비스명)을 확인.
