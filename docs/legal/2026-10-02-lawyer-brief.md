# 변호사 상담용 브리프 (2026-10-02)

> **이 문서는 법률 자문이 아니며, 상담 준비용 자료입니다.** 약관 원문 대부분은 조사 환경에서 열람하지 못했습니다(`2026-10-02-terms-fact-sheet.md` §1). 상담 전에 운영자가 원문을 직접 캡처해야 합니다.

## 1. 한 페이지 요약

**서비스**: 한국어 무료 주식 정보 웹서비스(코스피·코스닥). 로그인·광고·유료 없음, 개인 운영. 현재 외부 공개 배포 전(`docs/ops/pre-deploy-checklist.md`: 법률 항목 미결 시 배포하지 않음).

**데이터 흐름(텍스트 다이어그램)**
```
[공공데이터포털 금융위원회_주식시세정보 (원천: 한국거래소)]   [DART OpenAPI (금융감독원)]
            │ 일 1회 배치(서비스키, 호출 한도 내)                     │ 연 1회 수동 + 기업개황/재무
            ▼                                                    ▼
   raw_internal (원본 일봉, 비공개 스키마)              public_serving.corp_earnings (공시 수치, 직접 적재)
            │ 파생 지표 계산                      
            ├──▶ public_serving: 가공 지표(백분위·괴리율·이상치), 시장 요약, 패턴 조건 결과
            └──▶ public_serving.daily_prices (일봉 공개 복사본, DEC-041)  ◀── 스위치 PRICE_EXPOSURE (기본 켜짐)
                                  │
                      공개 API(FastAPI) ──▶ 프론트(Next.js) ──▶ 이용자(비로그인)
[한국투자증권 Open API] ──▶ 개인 PC 로컬 모드(분봉·호가·체결, 기본 꺼짐, 외부 공개 시 끔) ──▶ 내 PC 화면만
```

**화면**: 홈(전일 시장 동향 요약) / 조건 스크리닝 / 패턴 스크리닝 "급등 전 압축주"(조건 충족·미충족·산정 불가 표, 점수·순위 없음) / 종목 검색 / 종목 상세(차트·일자별 시세·실적·수급 준비 중·조건 체크·차트 요약) / 서비스 안내.

**주요 사용 문구(원문 인용, `frontend/src/content/copy.ko.json`)**
- "이 서비스는 투자자문업 등록 사업자가 아니며, 제공되는 정보는 투자 조언이 아닙니다. 투자 판단과 책임은 이용자 본인에게 있습니다."
- "이 서비스는 투자 판단을 대신 내려주는 서비스가 아니라, 이용자가 스스로 세운 조건에 따라 공개 데이터를 가공한 지표를 정렬·필터링해 보여주는 정보 조회 도구입니다."
- "이 목록은 가격·거래량 흐름이 아래 수치 조건에 해당하는 종목을 기계적으로 표시한 것입니다. 이후의 주가 움직임을 예측하거나 매수·매도를 권유하는 정보가 아닙니다."
- 푸터: "본 서비스는 원본 시세 데이터를 그대로 제공하지 않으며, 가공된 지표만 제공합니다." (**기본 설정에서 일봉 차트·표가 보이는 것과 불일치**, risk-matrix §5-A)
- 화면 명칭 "급등 전 압축주", 열 이름 "급등 이력", 단계 "돌파 직전/돌파 초입".

**데이터 약관 핵심(저장소 인용, 원문 대조 미완료)**: "본 데이터는 상업적 목적 여부와 상관 없이 제3자 무단 제공 및 재배포가 엄격히 금지됩니다. 만약 상업적 목적으로 이용할 경우 원천 소유자인 한국거래소의 KRX Data Marketplace에서 유료로 구매하여야 합니다. 이 경우에도 아래의 목적으로만 상업적 활용이 가능합니다: 1. 가공을 통해 독창성 있는 저작물을 생산 2. 제3자의 방문, 가입을 통한 간접 수익 창출"(`docs/harness/02-planning.md` §4-3). 2차 요약에는 "이용허락범위 제한 없음"도 있음(두 문구 관계 미확인).

## 4. 결정 트리

```
[Q1] 1~3번 질문 답: 원값 표시 가능/불가/불명확?
 ├─ 허용(서면으로 확인) ──▶ 스위치 유지(켜짐). 단, 푸터·안내 문구를 사실에 맞게 수정, 출처 표기 보강
 ├─ 불가 또는 계약 필요 ──▶ 두 스위치 false로 배포(가공 지표·실적만). KRX 정식 계약 검토는 사업 판단
 └─ 불명확/무응답 ───────▶ 두 스위치 false로 배포(user-action-guide 표와 일치), 추가 서면 문의

[Q2] 증권사 시세(로컬 모드)
 ├─ 개인 PC 한정 허용 확인 ─▶ 개인 이용만, 외부 서버에서는 계속 끔
 └─ 불명확/불가 ───────▶ 로컬 모드 미사용, 코드 기본 꺼짐 유지. 공개 서비스에는 어떤 경우에도 포함하지 않음(DEC-052 전제)

[Q3] 명칭("급등 전 압축주" + 서비스명)
 ├─ 문제 없음 ──▶ 유지, 푸트노트 "급등 이력" 문구는 별도 정리
 ├─ 표현 리스크 지적 ─▶ `copy.ko.json`의 `pattern.label` 단일 출처 변경, 또는 기능 스위치로 패턴 기능만 비공개 배포
 └─ 상표 충돌 ─▶ 서비스명 변경(확정 브랜드명 없음, A10)
```
