## (a) 공공데이터포털 / 제공기관(금융위원회·한국거래소)

- **보낼 곳**: 공공데이터포털 해당 API 상세페이지의 문의·Q&A 또는 고객센터(경로는 사이트에서 직접 확인). 검색 결과에서 금융위원회 "금융공공데이터" 담당 부서 연락처(전화 02-2100-2675)가 언급됨(**2차 확인**, 정확성 직접 확인 필요). 한국거래소 문의는 KRX 사이트의 문의 메뉴(위치 미확인).
- **대상 데이터셋**: 금융위원회_주식시세정보(https://www.data.go.kr/data/15094808/openapi.do, 열람 실패, 검색 결과 URL)
- **제목**: [문의] 금융위원회_주식시세정보 API 이용허락 범위(무료 개인 웹서비스의 일봉 표시·가공 지표 제공)

**본문**
안녕하세요. 개인이 개발 중인 무료 주식 정보 웹서비스에서 "금융위원회_주식시세정보" Open API를 사용하고 있어 이용 범위를 문의드립니다.

[서비스 개요] 코스피·코스닥 종목 정보를 보여주는 무료 웹서비스이며 로그인·광고·유료 기능이 없습니다. 하루 1회 API로 일봉 데이터를 수집해 자체 DB에 저장하고, 실시간 시세는 제공하지 않으며 화면에 "일 단위 종가 기준"과 기준일을 표시합니다.
[표시 방식] (1) 가공 지표: 등락률 순위 백분위, 이동평균 대비 괴리율, 거래량 이상치 점수, PER/PBR/시가총액 백분위, 조건 스크리닝, 시장 동향 요약 (2) 종목 상세에서 종목별 일봉(시가·고가·저가·종가·거래량)과 캔들 차트·일자별 시세 표(최근 약 60거래일) — 환경 설정으로 비공개 전환이 가능합니다 (3) 일봉 기반으로 가격·거래량 흐름이 일정 수치 조건에 해당하는지 표시.
[출처 표시] "데이터 출처: 공공데이터포털 금융위원회_주식시세정보"를 화면 하단에 표기합니다.

[질문]
1. 위 (2)처럼 일봉 원값(시가·고가·저가·종가·거래량)을 불특정 다수에게 표·차트로 표시하는 것이 상세설명의 "제3자 제공·재배포" 제한에 해당합니까? 해당하지 않는다면 허용되는 표시 범위(기간, 항목, 갱신 주기)가 있습니까?

3. 위 (1)처럼 원값이 아닌 가공 지표만 표시하는 경우는 제한이 있습니까? "가공을 통해 독창성 있는 저작물을 생산"의 기준은 무엇입니까?
4. 데이터셋 페이지의 "이용허락범위 제한 없음" 표기와 상세설명의 재배포 제한 문구의 관계를 어떻게 이해해야 합니까?
