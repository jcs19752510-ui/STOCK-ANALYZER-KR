# 종목 상세(C안) — 설계·개발 계획 (2026-10-02)

근거: 사용자 캡처(증권사 앱 관심종목·차트 화면) + DEC-041. **구조·정보 배치만 참고**하고 증권사 로고·고유 디자인은 쓰지 않는다.

## 1. 범위 (사용자 결정 반영)
| 영역 | 결정 | 비고 |
|---|---|---|
| 헤더(종목명·현재가·전일대비·등락률) | 구현 | 일 단위 종가 기준, 기준일 표시 |
| 차트 탭(캔들·MA5/10/20/60·거래량·MACD) | 구현(직접 SVG) | 새 의존성 없음 |
| 체결현황 → **일자별 시세 표** | 구현(일 단위 대체) | 호가 탭은 만들지 않음 |
| 투자자 탭(수급) | **보류** — "데이터 준비 중" 안내 | 공식 무료 출처 없음, 별도 결정 |
| 실적 탭 | 단계 2 | DART 확장(매출·영업이익) 필요 — 현재는 순이익·자본만 보유 |
| 뉴스 | **제외** | |
| 급등 전 압축주 조건 체크표 | 구현 | c1~c5·c9 충족 여부, 수급·실적은 "미반영" 표시. 서열·점수 표현 금지 |
| 관심종목형 리스트 행 | 구현 | 패턴 결과·검색 결과 행 스타일 |
유지 원칙: 비예측 고지 상시, 점수·순위·"추천/유력/TOP" 금지, 새 의존성 금지, 개발 DB에 가짜 데이터 금지(임시 DB로 테스트), 배포·커밋은 요청 시에만.

## 2. 설계 핵심 — 원값 노출 방식 (보안 설계 유지)
`api_service`는 `raw_internal` 접근 권한이 없다(0004, 2차 방어). 이 방어를 **풀지 않는다.** 대신 공개용 테이블 `public_serving.daily_prices`(종목·일자별 시·고·저·종가·거래량·거래대금)를 신설하고 Derivation Batch가 `raw_ohlcv`에서 복사한다(읽기 전용 `api_service`는 이 테이블만 SELECT).
- 이동평균·MACD는 프론트에서 일봉으로 계산(서버는 원자료만, 계산식 단일 출처 `chartIndicators.ts`, 단위테스트).
- 기존 `/screen`·`/screen/pattern` 응답의 원값 비노출은 **그대로**(이번 변경은 신규 엔드포인트 한정).
- 04-ux-design §4-3 "원본 캔들차트/시세표 없음" 원칙은 DEC-041로 종목 상세에 한해 대체됨(문서에 표시).

## 3. API (신규)
- `GET /api/v1/stocks/{code}/prices?days=120` — 일봉 배열(오름차순) + `meta.trade_date`, 전일대비·등락률은 서버 계산.
- `GET /api/v1/stocks/{code}/pattern-check` — 해당 종목의 조건 c1~c5·c9 충족/미충족/산정불가 + 정의(`/screen/pattern`과 같은 식·임계값 재사용).
- (단계 2) `GET /api/v1/stocks/{code}/financials`.
