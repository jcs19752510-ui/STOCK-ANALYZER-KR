## 구현하지 않은 것과 이유
| 요소 | 이유 |
|---|---|
| 호가·체결현황 탭(공개 배포) | 실시간 데이터 필요. 공개 배포에서는 "일자별 시세"가 대신하고, **개인 로컬 모드(DEC-052)에서는 호가·체결 탭이 생김** |
| 뉴스·비교 탭 | 기사 재배포 라이선스·범위 밖(DEC-041) |
| 분·틱 차트(공개 배포) | 일 단위 데이터만 수집. **개인 로컬 모드(DEC-052)에서는 동작**(내 PC 한정, 한국투자증권 앱키) |
| "AI로 차트 분석하기" 버튼 | **"차트 요약"으로 대체(DEC-052)**: 같은 위치의 검은 원형 버튼 + 안내 말풍선, 내용은 수치를 문장으로 옮긴 사실 요약(전망·투자 판단 없음) |
| 하단 앱 메뉴(홈·관심종목·현재가·주식주문·잔고) | 증권사 앱 고유 내비게이션 — 이 사이트의 홈/스크리닝/종목 검색 탭바 유지 |
| 가격축 옆 빨강·파랑 세로선 | 의미(기준)를 이미지만으로 확정할 수 없어 보류 |

## 추정·확인 필요 사항
- **매물대 계산식**: 이미지의 7구간 비중 합계가 100%임은 확인(KODEX 코스닥150: 6.62+30.39+6.02+11.04+1.72+6.43+37.77). 증권사의 실제 배분 방식(종가 기준인지, 봉 범위에 분산하는지)은 알 수 없어 **종가가 속한 구간에 거래량을 더하는 방식**으로 구현했다(화면에 근사값임을 안내). 숫자가 앱과 약간 다를 수 있다.
- 색 값은 이미지에서 눈대중으로 추출한 근사값(상승 `#d9342b`, 하락 `#1a6fc9`, 띠 `#d03232`/`#1f6fc5`).
