# 상단 영역 순서 변경(① 메뉴 → ② 회원 메뉴 → ③ 제목) 내부 시험 결과서 (DEC-082)

- 일자: 2026-10-06 / 브랜치: `PROD_SCH`
- **배포 안내**: Render 자동 배포(DEC-081)가 켜져 있으면 푸시 후 몇 분 안에 자동 반영된다. Render → `stock-analyzer-web` → Events에 새 배포가 안 보이면 알려 달라(자동 배포 동작은 아직 실제로 확인하지 못했다, `docs/qa/2026-10-06-auto-deploy-test-result.md` §5).
- 요청(사용자, 화면 캡처에 1·2·3 표시): 번호 순서대로 위치를 바꿔 달라. 1 = 메뉴 줄(홈·조건 스크리닝·종목 검색·관심종목), 2 = 회원 메뉴(정찬욱님·회원 관리·로그아웃·모든 기기에서 로그아웃), 3 = 서비스 제목. 화살표는 메뉴 줄을 맨 위(제목 위)로 올리는 방향.
- 결론: **자동 시험 612건 전부 통과.** 실제 휴대폰·운영 반영 확인은 아직(§6).

## 1. 결과 배치
| 위 → 아래 | 모바일·태블릿(<1024px) | 데스크톱(≥1024px) |
|---|---|---|
| 맨 위 | 면책 배너(변경 없음, 항상 고정) | 같음 |
| ① | 메뉴 줄(스크롤해도 배너 아래에 고정) | 같음 |
| ② | 회원 메뉴(이름 + 버튼들, 항상 자기 줄) | ③과 한 줄: 오른쪽 |
| ③ | 서비스 제목(홈 링크) | ②와 한 줄: 왼쪽 |
- 데스크톱은 한 줄에 둘 다 들어가므로 시각 순서만 제목(왼쪽) → 회원 메뉴(오른쪽)로 뒀다. 사용자 캡처가 모바일이라 이 부분은 에이전트 설계다(§5, 원하면 데스크톱도 ② → ③ 두 줄로 쌓을 수 있음).
- 로그인 전(회원 메뉴 없음): ① 메뉴 줄 → ③ 제목.

- 데스크톱에서는 키보드 Tab 순서(회원 메뉴 → 제목)와 화면 순서(제목 → 회원 메뉴)가 다르다. 모바일(문서 순서 = 화면 순서)을 우선했다. 데스크톱도 일치시키려면 ②·③을 두 줄로 쌓는 방식이 필요하다(세로 공간 약 56px 증가).
- 이전 시험 원본(`nav-top-test-raw.json`, `member-buttons-test-raw.json`)은 이전 배치 기준이다. 이번 배치의 기준 결과는 `header-order-test-raw.json`이다.
