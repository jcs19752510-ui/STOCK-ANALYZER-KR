## 5. 보안·표현 점검
- 앱키·시크릿은 코드·응답·로그에 없음(거절 응답 테스트로 확인). 주문·계좌 API 호출 없음.
- 문구는 사실 서술만(순매수/순매도 수치, 단위, "투자 판단의 근거가 아닙니다"), 해석·전망·행동 제안 없음. 금지표현 검사 통과.
- 공개 배포에서는 기존과 같이 `LOCAL_INTRADAY_ENABLED`·`NEXT_PUBLIC_LOCAL_INTRADAY_ENABLED`를 설정하지 않으면 API·화면 모두 꺼진다.

| 항목 | 상태 | 확인 방법 |
