# 차트 그리기 도구 버튼 무반응 개선 내부테스트 결과서

- 작성일: 2026-10-03 (KST) / 브랜치 `PROD_SCH` / 접수: 사용자 캡처(차트 오른쪽 위 ✎ 버튼을 눌러도 아무 반응이 없음)
- 환경: 임시 PostgreSQL + 시드, 모의 KIS, `next dev`, Playwright

## 1. 원인
- ✎(그리기 도구)는 증권사 앱 참고 화면의 모양만 재현한 버튼이고 **기능은 구현하지 않았다**(참고 화면 대응표 `03-reference-ui-spec.md`에 "도구는 비활성"으로 기록). 버튼이 `disabled`라 눌러도 반응이 없고 이유는 마우스를 올렸을 때 툴팁에만 있었다. 앞서 분·틱 버튼에서 같았던 문제와 동일한 사용성 결함이다.

## 2. 수정
- 버튼을 `aria-disabled`로 바꿔 누를 수 있게 하고, 누르면 차트 위에 안내를 표시한다: "그리기 도구(추세선·수평선 등)는 아직 제공하지 않습니다. 화면의 이동평균선·매물대·차트 요약으로 가격 흐름을 확인할 수 있습니다." 다시 누르면 닫힌다. 스크린리더에는 `aria-expanded`·`aria-controls`와 `role=status`로 알린다. 모양은 비활성처럼 보이되 명암비를 높였다.
- **그리기 기능 자체는 만들지 않았다**(범위·방식은 사용자 결정 대기: 추세선·수평선 등 어떤 도구를 어디에 저장할지).

## 3. 점검(`frontend/scripts/qa/draw-tool-notice.mjs`, 320/360/1280px, 16항목)
버튼이 눌릴 수 있음(`disabled` 속성 없음), 클릭 시 사유 안내 표시, `aria-expanded=true`, 가로 넘침 없음, axe 위반 없음(360px), 다시 누르면 닫힘 — 모두 통과.
