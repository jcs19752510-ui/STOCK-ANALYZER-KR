# 사고 재현 + fix_local_data 재실행 내부테스트 결과서 (2026-10-06)

대상: 로컬 PC에서 "최신 데이터가 아님 / 10-02 포기 경고"가 났던 사고를 임시 PG에서 재현하고, 실제 `scripts/fix_local_data.ps1`(PowerShell 7)로 복구되는지 확인.
실행: `PWSH=<pwsh> python tests/e2e/incident_repro.py` (모의 공공데이터 서버 + 실제 배치 + 실제 캘린더 로드).

## 결과 (수정 후 코드) — 8/8 통과
- 재현1 공개 전 5회 실행 후 발행일이 X 직전 거래일(2026-09-30)에서 멈춤
- 재현2 X에 NOT_PUBLISHED 실패 5회 누적(예전 코드는 여기서 영구 포기)
- 수정 후 X는 영구 제외되지 않음
- fix_local_data: X(2026-10-02) 원본 30행 채움 / 발행일 2026-10-06 = 기대 거래일 / 진단(후) [정상], rc=0 / X 이후 6개 날짜 모두 가공·발행 / 가공 보류 경고 없음

## 옛 코드 대조 (`--old-code`)
옛 `fetch_exhausted_dates`에서는 X가 시도 상한으로 영구 제외됨(재현 확인: 제외 목록에 포함) = 사고 원인 재현.
