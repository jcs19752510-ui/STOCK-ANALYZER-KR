# 데스크톱도 세 줄로 쌓기 내부 시험 결과서 (DEC-083)

- 일자: 2026-10-06 / 브랜치: `PROD_SCH`
- **배포 안내**: Render 자동 배포(DEC-081)로 푸시 후 몇 분 안에 반영된다(실제 자동 배포 동작은 아직 확인하지 못함, `2026-10-06-auto-deploy-test-result.md` §5). Render → `stock-analyzer-web` → Events에서 새 배포 시작 여부를 확인해 달라.
- 요청(사용자): "데스크톱도 모바일처럼 세 줄로 쌓아 주세요"(1·2·3 순서: ① 메뉴 줄 → ② 회원 메뉴 → ③ 제목). DEC-082에서 에이전트가 정한 "데스크톱은 ②·③ 한 줄"을 사용자가 바꾼 것.

- 데스크톱은 세로 공간이 DEC-082 대비 약 56px 늘었다(회원 메뉴 줄 + 제목 줄 분리). 로그인 전(회원 메뉴 없음)에는 늘지 않는다.
