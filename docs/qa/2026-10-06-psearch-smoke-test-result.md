## 3. 이 도구로 시험하는 목적에 대한 판정
- **실시간으로 데이터를 가져오는 시험이 가능한가**: 가능하다. 단 **장중(평일 08:00~20:00)에 내 PC에서 실제 앱키·HTS ID로 실행**해야 한다(개발 환경은 증권사 접속이 막혀 있음). 이 도구가 보여 주는 것: 조건 결과가 장중에 실제로 바뀌는가(편입·이탈 시각), 갱신 간격, 응답 필드, 지연, 한도.
- 방식은 **주기 조회(근실시간)**이며 푸시가 아니다.

## 4. 확인하지 못한 것·위험
1. 실제 증권사 응답 필드(공식 샘플은 23개 필드를 정의하나 이름 전체는 확인하지 못함), 장중 갱신 주기, 응답 지연, 호출 한도 — 모두 장중 실행 결과로만 확인 가능.
2. 0건일 때 증권사가 주는 오류 코드·문구(샘플은 "0건 시 오류 반환"이라고만 설명). 도구는 `UPSTREAM_ERROR`를 0건으로 간주하고 문구를 그대로(가려서) 보여 준다. 조건 키 오류와 구분이 안 될 수 있어 문구를 함께 확인하도록 안내함.
3. `user_id` 형식(샘플은 HTS ID, 대소문자 구분 여부 미확인).
4. 앱키 계정과 HTS ID가 다른 고객이면 거절될 수 있음(실패 시 안내에 포함).
5. 이 확인 결과가 나오기 전에는 사이트 화면을 만들지 않는다(견적 약 4영업일, DEC-087).
