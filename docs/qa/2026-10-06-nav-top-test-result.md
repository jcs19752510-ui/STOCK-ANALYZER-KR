# 상단 메뉴 이동·선택 표시 강화 내부 시험 결과서 (DEC-079)

- 일자: 2026-10-06 / 브랜치: `PROD_SCH`
- 요청(사용자): ① 운영 화면 맨 아래의 메뉴(홈·조건 스크리닝·종목 검색·관심종목)를 맨 위로 올릴 것 ② 메뉴를 선택했을 때 어떤 메뉴가 선택됐는지 명확히 표시할 것(기존 표시는 거의 안 보임).
- 결론: **자동 시험 285건 전부 통과.** 단, 운영(Render) 배포와 실제 휴대폰 화면 확인은 아직 못 했다(§6).

## 1. 변경 요약
| 파일 | 내용 |
|---|---|
| `frontend/src/app/globals.css` | 모바일 하단 고정 탭바(`position: fixed; bottom: 0`) 제거 → 머리글 안 전체 폭 한 줄(워드마크 아래, 회원 메뉴 위, 본문 위). 메뉴를 테두리 있는 버튼형으로 바꾸고, **선택된 메뉴는 브랜드색(파랑) 면 채움 + 흰 글자 + 굵게**. 하단 탭바용 본문 여백(+56px) 제거. 고대비 모드(`forced-colors`)에서는 굵은 테두리+밑줄. 좁은 폭(<380px)은 글자 13px |
| `frontend/src/components/GlobalNav.tsx` | 주석만 갱신(동작·DOM 불변: `aria-current="page"`로 선택 표시) |
- 데스크톱(≥768px)은 같은 상단 위치(머리글 오른쪽)를 유지하고, 같은 버튼형·선택 표시로 통일했다.
- 로그인·회원 메뉴·API·데이터 코드는 건드리지 않았다.

## 7. 알아둘 점
- 같은 "선택 표시"가 약한 다른 곳이 있다: 조건 스크리닝 화면의 모드 전환(직접 조건 설정 / 급등 전 압축주). 이번 요청 범위(전역 메뉴)가 아니라 바꾸지 않았다. 원하시면 같은 방식으로 맞출 수 있다.
- 메뉴는 화면을 내려도 따라오지 않는다(맨 위 고정이 아니라 머리글 안). 따라오게 하려면 별도 결정이 필요하다.
