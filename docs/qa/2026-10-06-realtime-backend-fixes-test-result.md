1. 실제 증권사의 거래일 경계 동작(체결의 `bsop_date`가 날짜 변경 시 언제 바뀌는지)과 NXT 장전 시간대(08:00~) 동작은 모의로만 확인.
2. REST 현재가는 장 시작 전에는 직전 종가일 수 있다(`source:"rest"`로 구분되나 화면은 아직 별도 표시를 하지 않는다).
3. 거래일 변경 알림은 **새 날의 첫 체결**이 올 때 나간다(그전까지 화면은 직전 날 상태를 보여 준다).
4. 다시 연결하면 거래일 변경 직후 상태는 `seeded=false`라 시작 값을 다시 받는다(날짜가 다르면 버리고 같으면 합침 — 위 시험으로 확인).
