# 소유자 전용 투자자 수급 내부 테스트 결과서 (DEC-068)

- 작성일: 2026-10-05 / 범위: 소유자 PC 수집 → Neon 적재 → 소유자 계정에게만 API·화면 제공. 다른 회원은 기존 "준비 중".
- 배경: KRX 약관(자동 수집·복제·배포 금지, 2025-12-27 로그인 회원제 전환)과 KIS 재배포 약관 미확인 때문에 제3자 제공은 하지 않는다(사용자 선택 4번).

## 1. 시험 환경
임시 PostgreSQL 16 + 실제 FastAPI + 실제 `next start` + Playwright. **실제 KIS 서버·Neon·Render가 아니다.** 수집 스크립트는 정규화 로직과 DB 적재만 시험했고 실제 KIS 호출은 시험하지 못했다(개발 환경에서 증권사 접속 불가).

## 3. 접근 통제 (세 겹)
① API 내부 토큰(웹 서버만) ② 웹 대행 경로가 **로그인 세션의 아이디**를 `X-Auth-Username`으로 전달(브라우저가 보낸 같은 이름 헤더는 무시, 시험: 위조 403) ③ API가 `PUBLIC_API_OWNER_USERNAME`과 다시 비교(설정 없으면 404). 화면의 `isOwner`는 서버가 계산하며 화면만 우회해도 값은 오지 않는다.

## 4. 미확인 / 한계
1. 실제 KIS 응답 필드·단위(주·백만원)·당일 확정 시각 미확인 → 소유자 PC에서 소수 종목 실행 후 증권사 앱과 대조 필요(DEC-054와 동일).
2. 전 종목 수집 소요 시간·KIS 호출 한도 실측 없음(요청 간격 0.12초 → 약 6분 추정).
3. Neon 실서버에서의 동작, 수집 PC가 꺼진 날의 공백(다음 실행 시 최근 30일이 다시 채워짐), 소유자 아이디 변경 시 두 환경변수 동시 수정 필요.
4. 소유자 1인만 보지만, 이 값을 다른 회원에게 열 때는 KIS 약관 확인이 선행되어야 한다.
5. AI는 운영 배포·Neon 변경·실제 KIS 호출을 하지 않았다.
